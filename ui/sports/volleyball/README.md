# Voleybol ekranları

Ortak bileşen ve branş navigasyonu aşamalarından sonra tek video yükleme ekranı burada kurulacak.
Video, zaman çizelgesi, metrik/kalite kartları ve karşılaştırma ortak `ui/components/` içinden alınacak.
Ekran hesaplama yapmayacak; voleybol analiz sonuçlarını gösterecek.
Henüz çalışan bir voleybol ekranı yok.
