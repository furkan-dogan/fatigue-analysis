# Tarihsel belgeler

Bu dosyalar önceki taekwondo/kickboks çalışmasının korunmuş belgeleridir.
Eski yollar, model planları ve doğrulanmamış yorumlar içerebilirler.
Aktif kurulum veya geliştirme talimatı olarak kullanmayın; kökteki README ve upgrade.md geçerlidir.

- `README.taekwondo.md`: taşıma öncesi README.
- `CLAUDE.taekwondo.md`: taşıma öncesi proje rehberi.
- `Deney_Protokolu.docx`, `Proje_Raporu.docx`: eski Word belgeleri, içerikleri değiştirilmedi.
